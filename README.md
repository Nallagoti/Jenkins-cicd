# Jenkins CI/CD Pipeline with Docker

## Project Overview
This project demonstrates a basic CI/CD pipeline using Jenkins, GitHub, Docker, and AWS EC2.

## Tools Used
- Git and GitHub
- Jenkins
- Docker
- AWS EC2
- HTML

## Pipeline Stages
1. Checkout source code from GitHub
2. Build Docker image
3. Test Docker image
4. Deploy the application using a Docker container
